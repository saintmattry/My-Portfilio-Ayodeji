Student Registration Portal

Developed a fully responsive student registration portal designed to streamline the enrollment process for academic institutions. The project focused on front-end architecture, user experience, form validation, and accessibility compliance to ensure the system is usable by all students, including those using assistive technologies.Core Development & Features:Built a multi-step responsive registration form using semantic HTML5 to capture essential student data including full name, email address, phone number, date of birth, course selection, semester, and preferred study mode. Used for native browser validation and better mobile UX.Implemented robust client-side validation with JavaScript to reduce server load and give instant feedback. Validation rules covered required fields, email format, minimum password strength, phone number formatting, and duplicate email checks against mock data. Error states display inline with clear, human-readable messages like "Please enter a valid email address" instead of generic alerts.Engineered form accessibility to WCAG 2.1 AA standards. Every input is paired with a related fields are grouped in fieldset with legend tags, and ARIA attributes like aria-invalid="true" and aria-describedby connect error messages to inputs. Tested with NVDA screen reader to ensure full keyboard navigability and logical tab order.UI/UX & Responsive Design:Styled the interface using CSS Grid and Flexbox for a mobile-first layout that scales seamlessly from 320px to 1440px+ screens. Grid handles the overall two-column desktop layout for form sections, while Flexbox manages button groups, inline field alignment, and vertical stacking on mobile.Designed custom form components without frameworks. Created styled radio buttons and checkboxes, custom select dropdowns with search functionality for 50+ courses, and a progress indicator for multi-step forms. Used CSS variables for theming — --primary: #00A389 — to match institutional branding.Added microinteractions and feedback states to improve UX. Input fields show focus states, success checkmarks on valid entry, and shake animations on error. Submit button displays a loading spinner during validation to prevent duplicate submissions.
